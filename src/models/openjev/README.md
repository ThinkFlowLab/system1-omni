# openjev/openjev

Work in progress for [RFC #95](https://github.com/ThinkFlowLab/system1-omni/issues/95): native support for
[openjev/openjev](https://huggingface.co/openjev/openjev/tree/ac97900fd034fdd7e7e536f3d4c21b836cae0750), a
Qwen3.5-based decision model that answers `choice`, `score` and `noul` by reading the scores of the option letters at
the first output position. It is a different checkpoint and contract from Open-Jev-27B-v1.1 and Open-Jev-9B
([`../open_jev/`](../open_jev/)): one prompt per question, no scalar head.

This crate holds the CPU half: the processor. There is no executor, worker binary or recipe yet.

- [`native/src/contract.rs`](native/src/contract.rs): request compilation into one text-lane prompt per question
  (`State:`, `Question:`, `Options:` with `[A] key: description` lines), instructions that are objects or arrays
  written as Python literals ([`native/src/pyrepr.rs`](native/src/pyrepr.rs)), and the typed answers from the
  candidates' scores: temperature softmax, score expectation, the yes/no sigmoid, the choice and score confidences,
  4-decimal rounding with the choice picked before rounding.
- [`native/src/processing.rs`](native/src/processing.rs): the chat template for one user message with thinking off,
  the prompt token ids, and the letter token ids in option order.

## Reference and settings

Everything follows `helper/shim.py` at ac97900 (sha256 `81a22f1b...`) with the serving guide's settings
(`serve/SERVE.md`): `READOUT_T=0.85`, `READOUT_NOUL_T=1.829074`, `READOUT_NOUL_BIAS=0`, `READOUT_TARGETED=1`,
`READOUT_INSTR_STYLE=pyrepr`, every other knob at its file default.

## Limits (rejected with an error, not approximated)

- More than 52 options (one letter each); the helper's multi-pass composition is a later step.
- A prompt over 16,384 tokens.
- A state with a screenshot (`screenshot` or `image` holding a data URL or more than 2,000 characters): the helper
  switches to its image lane, which needs the vision encoder.
- A state that is neither a string nor an object, and `noul` criteria that are not an object (the helper drops the
  connection on the latter).
- A missing or non-finite candidate score fails the request, as the helper does with `READOUT_TARGETED=1`.

Known gaps against Python: `str.isprintable` follows a fixed table of the non-printable assigned characters of
Unicode 15.0 (Python 3.12), so unassigned and private-use code points, and characters a later Unicode version
classes differently, may render differently; integers beyond 64 bits are read as floats.

## Tests

`tests/openjev/data/contract.json` is generated by [`tests/openjev/make_fixtures.py`](../../../tests/openjev/make_fixtures.py),
which runs the pinned helper unmodified against a fake OpenAI client: it records each prompt, the token ids the pinned
chat template and tokenizer give, the candidate token ids, fixed candidate log-probabilities and the helper's answer.
No model is loaded.

```sh
cargo test --locked -p omni-openjev-native
# with the pinned tokenizer.json in a folder (no weights):
OPENJEV_MODEL=path/to/openjev cargo test --locked -p omni-openjev-native --test tokenization -- --ignored
```

The weights are CC BY-NC 4.0 and are not distributed here; the helper is Apache 2.0, see
[`native/NOTICE.openjev-helper`](native/NOTICE.openjev-helper).
